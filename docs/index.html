Albert School, rangé pour toi

Tu te connectes une fois à Inside avec Google. Ensuite l'app vérifie tout chaque heure, même fermée.

  • Aujourd'hui et emploi du tempsTa semaine avec les salles, exportable vers Calendrier.
  • ExamensDates, durées, coefficients et le compte à rebours avant chaque épreuve.
  • PrésenceTon taux par unité et le nombre d'absences encore possibles avant le seuil de 85 %.
  • Cours rangés dans l'ordreLes supports d'Inside, de Google Drive et du Bureau, triés par catégorie : TD1 avant TD2, le corrigé juste après son sujet. Tu peux tout réordonner à la main.

Tout reste sur ton Mac

Ta session Inside, tes espaces, ton classement des cours et ta clé d'IA éventuelle sont gardés dans ~/Library/Application Support/Cours Albert Sync, lisibles par toi seul.

Aucun compte, aucune clé, aucun mot de passe n'est intégré à l'app. Un ami qui la télécharge part de zéro et met sa propre clé s'il le souhaite.

Le vault Obsidian et Google Drive pour ordinateur sont facultatifs.

Installer Cours Albert

  1. Télécharge l'appLe fichier Cours-Albert-3.3.2-macOS.zip, ou toutes les versions dans les releases.
  2. Glisse-la dans ApplicationsDouble-clique sur le zip pour le décompresser, puis dépose Cours Albert dans le dossier Applications.
  3. Autorise-la une foisL'app n'est pas notarisée par Apple. Au premier lancement, va dans Réglages Système, Confidentialité et sécurité, puis clique sur « Ouvrir quand même ».
  4. Choisis tes dossiersL'écran de bienvenue te demande où ranger tes cours, puis ouvre Chrome une seule fois pour te connecter à Inside.

Si macOS dit que l'app est endommagée

Retire la quarantaine dans le Terminal :

xattr -dr com.apple.quarantine "/Applications/Cours Albert.app"

Compiler toi-même

Il faut les outils en ligne de commande de Xcode et Node.js pour installer les dépendances.

git clone https://github.com/tomabanicevic/cours-albert
cd cours-albert/src && npm install && cd ..
bash build.sh
